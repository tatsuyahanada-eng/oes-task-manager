Migration — CSV / DUMP からの移行

      
    

    


    

      
      
      
      
      
    


    
    

      
      
    


    
    

      
      

      

        テーブルの全行を出力します（絞り込みを指定した場合はその結果）。
        画面に表示している件数とは関係ありません。
      

      

        
        
      

    


    
    

      

        移行元の DUMP から、宣言された型をそのまま読み取ります。
        CSV からの推定と違い、桁・NULL の可否・主キーまで正確に分かります。
        
    
          
  1. DUMP を読み込む — DB には触れません
    2. 
          
  2. 使いたいテーブルを選ぶ — 構成が「テーブル作成」タブに入ります
    3. 
          
  3. そこで、お試し取り込み → テーブル作成 → 取り込み と進みます
    4. 
        

      

      

        読めるのはテキストの SQL です
        （mysqldump / pg_dump -Fp / SQL Developer の DDL+INSERT / SSMS のスクリプト）。

        Oracle の .dmp、SQL Server の .bak、pg_dump の -Fc は
        バイナリのため読めません。テキストの SQL で出し直してください。

  1. CSV を読み込んで構成を推定する — DB には触れません
    2.

    4.
